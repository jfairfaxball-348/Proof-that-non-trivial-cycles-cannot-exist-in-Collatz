# Proof-state classifications

Every promoted handover must label new material using these categories:

- **Proved analytic mathematics:** a stated theorem with complete proof and scope.
- **Exact finite certificate:** gap-free, reproducible finite computation with its exact range and verifier.
- **Externally inherited certificate:** accepted from a frozen incoming ledger after the required current integrity/fast checks; retain provenance.
- **Computational evidence:** observations or experiments that do not establish a theorem.
- **Conjecture / candidate lemma:** a proposed statement still requiring proof or disproof.
- **Method barrier / dead route:** a documented failure mode or countermodel limiting a strategy.
- **Repaired or demoted claim:** an explicit correction, including the first invalid dependency and remaining valid scope.
- **Open obligation:** a condition required for a named target, Gate, or global conclusion.

No finite evidence becomes an analytic theorem, no branch result becomes global, and no repair may be silent. In particular, a large elimination cannot close a global Gate or the Collatz conjecture without all inherited obligations being discharged.
