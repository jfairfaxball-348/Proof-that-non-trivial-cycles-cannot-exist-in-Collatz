## Main findings

### 1. The bounded verified-interval branch acquires an H21-specific physical floor

Using the exact RL217 prefix/window reconstruction, the minimum phase-16 odd state over the larger non-deleted pre-phase-51 family is

`63,923,554,738,764,449,832,959`.

The phase-51 family is a subset. If a survivor extends to a physical H21 word, the exact height recurrence and the inherited tiny positive `lambda=2^A/3^L` gap imply that no accelerated odd state, nor any intervening even shortcut state, can fall below one eighth of this value during a complete period:

`7,990,444,342,345,556,229,119`.

The peer-reviewed stable computational verification limit `2^71` is much lower. Thus `[1,2^71]` cannot simply be used as a physical endpoint set for this branch; an arithmetic candidate would still need an exact trajectory/equality certificate showing that it enters the interval, which would then certify that candidate as nonphysical/blue.

### 2. Unbounded dyadic rays still do not create k-class compression for a finite word library

RL218 had already shown fixed seed + fixed word gives at most one k. RL219 extends this to an **unbounded** seed ray.

For a fixed raw word w applied to `2^t s`, endpoint values grow by at least a factor two each time t increases. The whole current e=16 root band has width only about 1.256 and exactly satisfies `R_MAX<2R_MIN`. Therefore a fixed `(seed,word)` pair can place at most one endpoint value anywhere in the entire root band, no matter how far the dyadic ray is extended.

A finite seed set and finite fixed-word library therefore remains a finite singleton-probe mechanism, not a source of non-singleton k residue classes.

## Strategic consequence

The existing compressed sources are now sharply separated:

- the stable bounded verified interval lies below the physical H21 floor and still needs equality-level candidate capture;
- finite fixed-word/dyadic-ray libraries are structurally sparse in the current root band;
- RL218 already screened the explicit RL80 LTE comb to zero intersections;
- fixed seed reverse-tree growth is already known to be a singleton architecture.

The plausible surviving blue route therefore needs a **new unbounded family with genuinely varying non-dyadic structure**, ideally an additive/affine progression or a parameterized word family whose exact endpoint formula aligns with the RL k lattice.
