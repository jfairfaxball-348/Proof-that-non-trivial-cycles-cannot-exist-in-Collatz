# RL231 verification

Portable fast suite:

```bash
bash verification/run_fast_rl231_verifiers.sh
```

The main verifier uses only Python's standard library and exact integer/Fraction arithmetic. It reconstructs the relevant RL187 ownership rows, checks the promoted full-prefix rank cores, executes every promoted recurrence atom over the complete stated ranges, replays the inherited RL191 extremal scan dependency, verifies the fixed-origin and K-boundary rational inequalities, and recomputes the final sparse-family charging floor.

`verify_rl231_proof_state.py` checks the frozen scope/gate/frontier state.
