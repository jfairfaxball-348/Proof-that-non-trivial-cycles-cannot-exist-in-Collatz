# RL227 — realistic RL closure roadmap and exhaustive fallback route tree

Date: 2026-09-01.

**Classification: strategic proof architecture / dependency synthesis. No new mathematical theorem, finite rank certificate, Gate closure, or global cycle exclusion is claimed in RL227.**

## 0. Executive result

RL227 answers the question:

> **What realistically remains to close RL on the path we are currently taking?**

The strongest current local engine is now the candidate-coupled H21/root-window/height machinery. It is no longer merely speculative: RL224 exhausted the complete inherited `e=16` arithmetic family and deleted terminal rank `34,124,151,203`; RL225–RL226 transferred the method to `e=4` and reduced that exact family to **3,856,660,232** combined arithmetic survivors through transition 43.

That is genuine progress, but it also exposes the scale problem. Deleting `e=4` would delete **one more terminal rank**, while the frozen necessary terminal-rank frontier contains **13,415,865,870** ranks. Therefore the closure programme must not become an indefinite sequence of single-rank victories. The immediate purpose of `e=4` is now twofold:

1. try to delete its live terminal rank exactly; and
2. more importantly, force a **reusable exhaustion theorem/engine** that can act on whole rank families rather than one hand-crafted offset at a time.

The current shortest plausible retained-architecture chain is:

`reusable rank-family exhaustion`
→ `physical H21 incidence/charge bridge`
→ `sole-high-branch contradiction`
→ `Gate A closure/lift`
**plus independently**
`Gate B closure`
→ `global nontrivial-cycle exclusion`.

A stronger direct full-phase/global contradiction may bypass Gate A and Gate B entirely, but no such theorem is currently proved.

The route tree below attaches an explicit **CONTINUE / PIVOT / RETIRE** rule to every major branch and terminates in a structured **SYNTHESISE NEW SOLUTIONS** fallback rather than an unnamed “try something else”.

## 1. The actual finish line

The following statements are not interchangeable.

### 1.1 Delete one terminal rank

Example: RL224 excluded terminal rank `34,124,151,203` by exhausting the complete inherited `e=16` arithmetic family.

This is a real exact deletion. It reduces the necessary-rank frontier by one.

It does **not** by itself:
- exhaust all small offsets;
- contradict the whole sole high branch;
- close Gate A;
- close Gate B;
- exclude all nontrivial cycles.

### 1.2 Exhaust one small-offset family

For `e=4`, the live terminal rank is `31,435,476,727` and the exact combined arithmetic remainder through transition 43 is `3,856,660,232`.

If that family is proved empty under the exact inherited bridge, the consequence is another terminal-rank deletion. The same warning applies independently to `e=28,33,40,45`: no `e=4` formula may be transferred to them by analogy.

### 1.3 Contradict the sole high branch

A theorem excluding every physically valid realization in the retained sole-high-branch architecture would be much stronger than deleting isolated ranks. But the branch conclusion must still be connected to Gate A at its exact inherited scope. A branch contradiction is not silently promoted to Gate A closure.

### 1.4 Close Gate A

Under the retained RL reduction, Gate A is the terminal area/valuation side. Historical exact work closes even terminal `k` and the `k<=25` sector, but Gate A remains globally open.

A proof that a specific H21/rank family is impossible is not Gate A unless an exhaustive lifting theorem covers every Gate-A counterexample.

### 1.5 Close Gate B

The exact primitive/full-`D` radius-3 obstruction is already a closed local theorem, but the global bridge that manufactures its hypotheses is open. Gate B remains independently open.

RL206 closes broad *method families* of additive recurrence compatibility and bounded fixed-arc rational residuals. It does not close all quotient-sensitive, modulo-`D^2`, nonrational, strict-excursion, ownership-packing, or owned-close-pair possibilities.

### 1.6 Global RL / nontrivial-cycle exclusion

The retained closure architecture requires:

`Gate A CLOSED` **and** `Gate B CLOSED`

unless a stronger theorem bypasses that split and directly excludes every hypothetical nontrivial cycle.

RL227 therefore rejects the shortcut “finish e=4 → RL closed”.

## 4. Primary route: staged plan with decision rules

### P1 — uniform candidate-coupled height exhaustion engine

**Certified input.** RL226 supplies the exact `e=4` affine root family, the finite `k` window, terminal-Hensel deletion, deterministic mandatory-height law, and lossless cylinder state.

**Missing object.** An endpoint-aware exact representation and/or theorem that controls state growth while preserving the residue translation needed for finite-window cardinality.

Acceptable mechanisms include:
- endpoint-aware residue automata;
- BDD/transducer compression;
- quotienting with a proved exact endpoint statistic;
- a direct analytic exhaustion inequality that bypasses explicit state enumeration.

**Success.**
- strongest: empty the full `e=4` family and prove the method in parameters reusable beyond `e=4`;
- acceptable: prove a reusable uniform lemma with exact new contraction even if `e=4` remains nonempty;
- strategically useful failure: prove a precise state-growth/scaling barrier showing why this engine cannot globalize.

**CONTINUE** only if each bounded session produces either a new exact invariant/compression theorem, a parametrically reusable criterion, or decisive contraction on a provably controlled state space.

**PIVOT** if work reduces to “advance transition 44, 45, 46, …” without a new uniform control theorem.

**RETIRE** naive `(phase,precision)` merging permanently at the current exact scope; RL226 already disproves its losslessness.

### P2 — offset-specific bridges for `e=28,33,40,45`

These offsets remain mathematically separate.

For each offset, require:
1. an exact inherited selector/phase anchor;
2. a gap-free root progression/window;
3. terminal constraints;
4. its own candidate-coupled height recurrence;
5. an exact verifier over the claimed family.

**CONTINUE** if the P1 engine consumes the new interfaces with parameter substitution that is formally proved.

**PIVOT** if every offset requires a new bespoke derivation with no common theorem emerging.

**RETIRE** any claim that `e=4` formulas apply “by similar reasoning” without an exact derivation.

### P3 — uniform rank-family deletion theorem

This is the scale checkpoint.

A primary closure route must move from a handful of named offsets to a theorem that deletes or bounds a *class* of necessary ranks: for example via a root-cone, a uniform terminal-height incompatibility, or a rank-family ownership restriction.

**CONTINUE** if the theorem reduces a quantified family whose size grows with the remaining frontier.

**PIVOT** if progress remains one rank per session. Even perfect success at that cadence is not a realistic route through `13,415,865,870` ranks.

**RETIRE as primary** isolated-rank exhaustion if no family parameter can be exposed. Keep it as a certificate tool and red-team laboratory.

### P4 — physical H21 incidence / exhaustive charge bridge

This is a common global dependency that local arithmetic work cannot silently skip.

The arithmetic H21 candidate families are necessary candidate calculations conditional on the inherited physical setup. A closure route needs one of:

- a theorem that every relevant physical sole-high-branch realization contains the required H21 source in the certified scope; or
- an exhaustive charge/cover theorem assigning every counterexample to one of the certified H21/rank families; or
- an alternative direct branch contradiction that eliminates the need for H21.

**CONTINUE** when a proposed bridge uses actual physical/full-word ownership, not only a local recurrence.

**PIVOT** to the direct high-branch or owned-macro routes if physical incidence cannot be made exhaustive.

**RETIRE** any local construction/no-go as a necessary physical predicate unless the bridge is proved; this preserves the RL221 type-safety lock.

### P5 — sole-high-branch contradiction and Gate-A lift

Once a uniform rank consumer and physical coverage exist, prove the exact contradiction for the sole high branch.

Then separately prove the exact logical lift from that branch result to Gate A if it is not already part of the theorem.

**CONTINUE** only with explicit quantified coverage.

**PIVOT** to a direct Gate-A theorem if branch bookkeeping is the only remaining obstruction.

**RETIRE** any wording that equates a branch result with Gate A without the lifting implication.

## 5. Gate-B route — required independently

Gate B cannot be postponed conceptually until Gate A is solved; the retained architecture ultimately needs both.

### Live Gate-B consumers after RL206

The following remain legitimate because RL206's barriers are scoped:

1. **owned strict-excursion / population-packing theorem** using full `D|Q` ownership;
2. **quotient-layer information beyond additive recurrence compatibility**, e.g. `Q/D mod D`, modulo-`D^2`, or another owned endpoint invariant;
3. **nonrational / order / sign / size operation** with an exact full-word premise;
4. **owned close-pair / radius bridge** that genuinely distinguishes the RL20 `D∤Q` fake and manufactures every radius-3 theorem hypothesis;
5. **ordinary `+1` non-homogeneous discriminator** that fails generalized-increment fake dynamics.

### Gate-B decision rules

**CONTINUE** if the candidate uses a premise unavailable to the RL20 fake and survives immediate coboundary/proper-factor reduction.

**PIVOT** after the natural residual family is proved to collapse to RL206's compatibility module, a fixed-arc rational constant, or an uncontrolled scale.

**RETIRE** raw same-modulus additive recurrence residuals, raw phase numerators, and known proper-factor/state-coboundary restatements.

A successful exhaustive Gate-B bridge has extremely high leverage because the radius-3 obstruction is already locally closed.

## 6. Major fallbacks

### F1 — endpoint/return-defect consumer

If P1 state compression stalls, try a genuinely independent endpoint consumer:
- quotient-root residue at a higher owned modulus;
- modulo-`D^2` information;
- endpoint-aware return defect;
- an exact order/sign restriction tied to the finite root window.

Do **not** count a selector as progress unless a theorem consumes it into deletion, contradiction, or a finite exhaustive reduction.

### F2 — physical H21 first

If rank arithmetic becomes too bespoke, move P4 earlier. A physical incidence/charge theorem can change which arithmetic predicates are actually common to all counterexamples and may expose a more uniform consumer.

### F3 — owned zero-area / active-weight / macro packing

Revive the RL72/RL75 Gate-A architecture only in its modern owned form.

The theorem must price synchronized zero-area depth or active-rank weight using full phase/ownership and must explicitly distinguish:
- RL74's canonical shrink/growth pump family;
- RL20's `D∤Q` local-grammar fake.

Pure endpoint mass, local grammar, or separable rank weights are already barrier-limited.

### F4 — product/growth/continued-fraction + modern full phase

This remains a deliberate global alternative. It is worth a session only after deriving a new RL-specific restriction on reduced ratio/gcd/convergent structure. Merely extending a finite continued-fraction cutoff is not enough.

### F5 — two-scale Diophantine pump incompatibility

Use competing shrink/growth pumps only if full phase reduces them to a bounded-parameter exponential/Diophantine equation. If arbitrary context coefficients proliferate, stop before invoking heavy external theory.

### F6 — Farey/cascade branch-to-global lifting

Resume finite depth/cascade work only after proving a global cover/domination trigger that makes a finite frontier exhaustive. More raw scan depth without a lifting theorem remains branch evidence.

### F7 — direct full-phase/global bypass

Highest risk and highest upside.

Target a theorem that directly excludes every nontrivial full-word completion, bypassing Gate A and Gate B. It must evade:
- raw phase-numerator size barriers;
- proper-factor/state coboundaries;
- RL206 additive compatibility collapse;
- local integrality constructions.

A genuine bypass theorem ends the retained route tree immediately.

**Why:** potentially closes Gate A in a much more uniform way than rank-by-rank exhaustion.

Global and potentially powerful, but they need a new bounded-parameter theorem before substantial computation or external machinery is justified.

Useful only after branch-to-global coverage becomes theorem-shaped.

**Highest-risk / highest-upside route.** It could make both Gates unnecessary.

The P1 uniformization attack is especially valuable: failure can be promoted as an exact state-growth/endpoint-information barrier, preventing repeated transition-by-transition work. Gate-B residual work has similar value if it closes a whole natural residual family as RL206 did.

Across multiple routes the recurring missing information is:
- genuine full-phase/ownership use rather than local compatibility;
- physical incidence/charge or an equivalent exhaustive cover;
- control of arbitrary context / synchronized zero-area depth;
- a valid branch-to-global lifting theorem.

These deserve higher priority than another isolated residue digit.

Rank new routes by closure leverage, independence, and dependency depth—not novelty or aesthetic appeal.
