# RL148 target — negative-defect fibre coupling

Start from the RL136 owned isolated-excursion theorem, not from bare
determinant-shell enumeration.  In its certified range, every `h=-1` phase is
an actual near-minimum state congruent to `3 mod 4`, exits to an odd state
congruent to `-1 mod 3`, and has a dyadic entry boundary of depth `H+c`.

Seek an ordinary-owned coupling between two or more of these three fibres:
dyadic entry depth, mod-4 negative state, and mod-3 exit state.  A promoted
result must use actual cycle states and must distinguish realised excursions
from candidate lattice positions.  Useful outcomes include an injectivity,
spacing, return, or global packing theorem that sharpens the existing
triangular exceptional-shell bound.

If no such coupling is available, freeze the precise obstruction rather than
turning a state ceiling or raw shell count into a cycle exclusion.  Preserve
RL20, RL79, RL81, primitivity, and all scope locks.
