# RL160 — global historical crossover audit target

## Purpose

Determine whether the accumulated RL corpus contains older proved material that can strengthen the current attack but has fallen out of recent handovers because the active proof state became compressed around newer branches.

The central question is not “are old sessions still mentioned?” but:

> Which old results are mathematically reusable **now**, which are already subsumed, which are blocked/demoted, and which combinations across distant eras have never been tested against the present frontier?

## Coverage

Survey all completed RL sessions discoverable in `sessions/` and relevant historical material in `Archive/`, from the earliest available RL work through RL159. Give extra attention to results older than the most recently cited ~50 sessions so the audit is not recency-biased.

## Method

Use promoted reports, proof-state ledgers, correction/demotion ledgers, route maps, completion reviews, and target handovers as the primary evidence. Build a normalized lemma/resource catalogue. Cross-reference it against the RL159 open frontier. Work concrete synthesis attempts where compatibility looks plausible.

Apply verification economy: do not recursively rerun expensive old certificates unless a concrete synthesis depends on an unresolved definition/certificate or a stop-and-repair trigger appears.

## Mandatory classifications

For each materially relevant historical resource, classify it as one of:

- live and directly reusable;
- live but missing a bridge;
- subsumed by a later stronger result;
- branch-specific / scope-limited;
- blocked by a certified method barrier;
- demoted/repaired and unsafe in original form;
- computational evidence only;
- redundant for the current frontier;
- uncertain and requiring targeted revalidation.

## Mandatory synthesis questions

Test whether older resources can combine with the current singleton-owner/physical-root framework, including at minimum crossovers involving:

- early geometric/radius/word/cylinder structure;
- Farey, phase-digit, backward-ladder, and full-phase results;
- 2-adic covering/frontier/packing and reset-budget work;
- global route-map and tournament conclusions;
- blue dyadic funnel / certified-basin ideas;
- cascade/interval propagation and later physical ownership restrictions;
- RL151–RL159 singleton/phase/dense-resultant developments.

The aim is not to force a synthesis. A high-quality negative result is an explicit incompatibility/barrier map that prevents future repeated rediscovery.

## Closeout

RL160 must end with an updated global resource map and a concrete RL161 target chosen from the strongest surviving crossover or, if none survives, from the clearest genuinely open gap revealed by the audit.
