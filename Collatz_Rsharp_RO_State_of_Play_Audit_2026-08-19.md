## Executive verdict

The RO programme is now much better positioned than it was at the previous 2026-08-18 audit because the old generic “proliferation does not imply contradiction” gap has been replaced by two exact endpoint mechanisms:

1. the **xi barrier**: every red integer `y` satisfies `xi(y) >= R#+1`; and
2. **Harmonic Regeneration Overpacking**: a repeatable bounded-dilation family of distinct red physical states with strict weighted physical `s=1` gain `>1` is impossible.

In RO, exact inverse path words are physically injective, so path-labelled regeneration has the required distinctness once ownership/prefix issues are handled.

The direct XCORL programme was designed precisely to connect a hypothetical least red state to one of those already-closed endpoints. In that direct architecture, **XCORL is now the dominant remaining central bridge and there is no comparable downstream gap**. If global XCORL-A or global XCORL-B were proved exactly as specified, RO would be excluded after a short formal composition with already-frozen lemmas.

However, “XCORL” is not one small local lemma. It currently packages several hard requirements:

- coverage of every admissible least-red 3-adic state, not merely one `7 mod 3^86` cylinder;
- an exact finite/infinite closure or unavoidability theorem for the state system;
- a successful endpoint alternative on every surviving state: xi descent or repeatable owned harmonic regeneration;
- exact handling of slack/height, common-tail legality, and ancestry ownership;
- if scalar local regeneration fails, a vector-valued multi-state mechanism or a rigorous dual obstruction.

The latest hostile-cylinder certificate is therefore a **major narrowing result**, not a near-completion result. It proves that three simple repairs of the one-shot 7-shadow certificate do not work in the stated finite envelope:

- same-shadow nested recurrence;
- reuse of the same frozen library across shadows;
- uniform fresh scalar re-centering on every nonzero shadow.

The programme should not return to those routes without changing the theorem class.

## Answers to the required audit questions

### 1. If XCORL-A were proved tomorrow, what remains before RO is excluded?

If **global XCORL-A** is proved in the sense of the frozen theorem specification—every admissible least-red state is forced into an exact xi-forbidden state—then no additional nontrivial RO theorem remains. The composition is:

`R# exists -> generated state is red -> XCORL-A gives xi(z)<R#+1 -> frozen xi barrier gives contradiction`.

Only proof integration/formalisation remains. RO path injectivity is not needed for the xi endpoint itself.

### 2. If XCORL-B were proved tomorrow, what remains before RO is excluded?

If **global XCORL-B** is proved as specified—every non-xi state lies in a finite ownership-safe bounded-dilation regeneration system with one explicit uniform `epsilon>0`—then RO closes by:

`XCORL-B -> exact path-labelled distinct red generations -> RO path injectivity -> Harmonic Regeneration Overpacking -> contradiction`.

Again, no comparably difficult downstream theorem remains. The requirements that the system is closed/repeatable and covers every surviving admissible root are part of XCORL-B itself, not later lemmas.

### 3. Is XCORL genuinely the last central mathematical bridge?

**Yes, on the current direct-RO mainline, with an important qualification.** The endpoint and physical-distinctness theorems are already frozen. The old pure-corridor/mixed-word gaps can be bypassed if XCORL works directly from least-red states.

But XCORL is a large compound bridge, not a single narrow lemma. Its unresolved internal components—global cylinder coverage/unavoidability, exact enriched state closure, and a uniform A/B endpoint alternative—are themselves comparable in difficulty. So the correct statement is:

> XCORL is the last central *architecture-level* bridge on the direct RO route, but it still contains several serious theorem-sized subbridges.

If XCORL-C instead proves the defined class incapable of closing, the programme falls back to the older excursion/packet route, where mixed-word integration and corridor-scale endpoint production again become critical gaps.

### 4. Which theorem-level infrastructure is reusable independent of XCORL?

Most importantly:

- least-red forward/inverse closure and minimality;
- exact pure-`r=1` arithmetic and supercritical `r=1` frequency bound;
- exact affine/common-tail packet representation;
- neutral-ray quotient and xi structure;
- three-shared-digit `17/40` growth/cash theorem and Hölder conversion;
- saturated inverse/xi identity and red xi barrier;
- RO exact inverse-path injectivity;
- Harmonic Regeneration Overpacking and its excursion-return version;
- packet occurrence-to-path injection in the pure-corridor grammar;
- phase-0 local recycle cancellation and the 3-adic/Kraft criticality theorems.

These remain useful even if the present XCORL class is abandoned.

### 5. Which approaches should be removed from the active road map?

Remove as active primary routes, while retaining their certificates as guardrails:

- one-shot positive density/proliferation as a contradiction;
- same-7-shadow nested recurrence of the frozen certificate in the stated envelope;
- iteration of the same 345,183-word library across shadows;
- uniform fresh scalar re-centering over all nonzero shadows in the stated finite class;
- fixed/local prefix-free harmonic library plus finite residue reweighting as a route to uniform strict gain;
- local recycling of phase-0 `3/2` gain through the same parent as independent resource;
- “almost prefix-free” rescue of the 1,095-word rho library;
- naive deletion of phase-0 endpoints or naive fixed-depth/leaf return surfaces on the frozen hostile corridors;
- renewed optimisation of older packet exponents unless required by a new endpoint-aware construction.

### 6. What is the smallest plausible next theorem that materially reduces the distance to RO closure?

The best next target is a **Hostile-Cylinder Vector/Dual Escape Theorem**:

> For the explicit hostile `3^83` cylinder, after enlarging the state to carry exact xi/height slack, cross-shadow type, ownership token, and a rigorously stated dilation budget, prove one of:
> 1. every hostile state reaches an xi-forbidden state;
> 2. the hostile state belongs to a finite vector-valued ownership-safe regeneration system with spectral/Collatz harmonic gain `>1` and exact rational certificate; or
> 3. an exact positive dual potential certifies gain `<=1` on the whole unavoidable hostile closure.

This is smaller than global XCORL but attacks the first explicit obstruction that defeats scalar recurrence. Either a vector rescue or a dual no-go would materially change the global road map.

### 7. What direction does the hostile cylinder favour?

Ranked recommendation:

1. **Vector-valued multi-state regeneration, coupled to a dual Bellman search.** The local scalar value can be `<1` while a multi-state cycle is supercritical; primal and dual should be attacked together.
2. **Xi/slack refinement as a live state variable.** The zero-kill result is cylinder-universal only inside the tested local envelope; tail/height-sensitive xi pressure remains genuinely open.
3. **Dual XCORL-C obstruction.** The exact criticality theorems plus an explicit hostile cylinder make a rigorous dual certificate a serious possibility, not merely a fallback.
4. **Nonlocal ownership transfer.** Required for correctness of any phase-0/vector rescue, but ownership alone cannot fix the scalar hostile value because the current local Bellman is already an upper bound before extra ownership restrictions.
5. **Endpoint-only dilation / overshoot-recovery paths.** Worth a controlled experiment, but the representative cap curve gives little evidence that modest prefix-cap enlargement alone will restore criticality.
6. **Broader strategic pivot.** Premature before the enriched vector/dual hostile closure is tested. There is still real local supercritical structure elsewhere, so the current architecture has not yet earned abandonment.

## Distance to RO closure

### Qualitative assessment

The programme is **late in architecture discovery but not late in proof completion**. The finish mechanism is now explicit and correct; the decisive global bridge is not.

The strongest positive strategic fact is that a successful global XCORL-A/B theorem would now plug directly into already-proved endpoints. The strongest negative fact is that the obvious scalar/local recurrence repairs have been rigorously defeated, including by an explicit hostile cylinder with a large margin below 1.

### Quantitative architecture score

A percentage can be made meaningful only as a score of **identified proof architecture**, not probability of solving RO.

Using the following weighted RO milestones:

- least-red foundations / closure / RO branch — 10%;
- endpoint contradiction mechanisms — 20%;
- physical path distinctness and path labelling — 10%;
- reusable local packet/neutral/harmonic infrastructure — 15%;
- finite XCORL discovery and obstruction mapping — 15%;
- global XCORL state coverage/unavoidability — 10%;
- global XCORL A/B recurrence-or-xi theorem — 15%;
- final formal integration — 5%;

this audit places the programme at approximately **55–60% of the mapped RO architecture**.

That number does **not** mean a 55–60% chance of a proof, nor that 55–60% of the mathematical difficulty is solved. The remaining 40–45% contains the highest-risk theorem: global XCORL closure. A single large unresolved bridge can dominate the actual difficulty.

A more conservative critical-path statement is therefore:

> The programme has solved most of the endpoint architecture and local infrastructure, but has not yet solved the one global recurrence/descent theorem that would make those tools decisive.

## Audit verdict

The direct RO programme remains viable enough to justify another focused theorem attack. The next session should not continue scalar re-centering, fixed-library iteration, or same-shadow nesting. It should attack the explicit hostile cylinder with an **enriched vector-valued primal/dual XCORL state**, with xi/slack and exact ownership built in from the start.

If that enriched hostile closure yields a supercritical finite vector system, the next task is global cylinder coverage. If it yields a rigorous unavoidable dual obstruction, the project should freeze XCORL-C for that enlarged class and decide whether to expand the class once more or pivot back to the mixed-excursion architecture.
