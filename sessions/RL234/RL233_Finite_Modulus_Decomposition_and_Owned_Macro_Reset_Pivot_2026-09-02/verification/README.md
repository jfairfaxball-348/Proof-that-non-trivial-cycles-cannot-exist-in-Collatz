# RL233 verification

Portable standard-library verifier suite.

- `verify_rl233_finite_modulus_decomposition.py`: exhaustive RL232 depth-three regression for the finite-modulus decomposition theorem.
- `verify_rl233_proof_state.py`: proof-state/successor/scope guard.

The finite replay is regression support only; the arbitrary-depth modular decomposition is proved analytically in the main report.
