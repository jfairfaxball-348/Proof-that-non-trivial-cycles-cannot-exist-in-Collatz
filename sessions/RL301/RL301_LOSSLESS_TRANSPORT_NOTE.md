# RL301 — lossless connector transport note

This connector closeout follows the documented individual-blob transport convention already used by RL300.

Every load-bearing handover payload is promoted as an individual UTF-8 Git blob under `sessions/RL301/` or `authoritative/`. `sessions/RL301/SHA256SUMS.txt` covers every frozen RL301 payload except itself.

No opaque ZIP is required for this connector transition. Integrity is supplied by:

- the internal SHA256 manifest;
- clean local reconstruction and fast-verifier replay before promotion;
- Git blob/tree identities;
- one atomic commit based on the recorded base tree;
- one fast-forward `main` ref update;
- post-commit remote readback.

Generated knowledge catalogues are not regenerated by the connector worker and remain `stale/deferred`, per repository policy.
