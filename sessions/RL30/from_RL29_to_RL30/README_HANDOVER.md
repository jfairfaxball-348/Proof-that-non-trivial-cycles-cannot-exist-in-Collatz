# RL29 -> RL30 Audit/Review handover

This bundle is designed for a **skeptical audit session**, not a blind continuation.

Top-level files:

- `START_HERE.md` — mandatory entry point.
- `RL29_AUDIT_LEDGER.md` — status classification and review checklist.
- `RL29_SESSION_RESULTS_TO_AUDIT.md` — self-contained derivations from the RL28/RL29 session.
- `RL29_BRIDGE_DISTANCE_AND_CLOSURE_MAP.md` — current assessment of how the new results could, or could not, reach a global RL contradiction.
- `NEXT_SESSION_AUDIT_KICKOFF_PROMPT.md` — ready-to-paste kickoff for the next session.
- `RL29_AUDIT_RELEASE_VERIFICATION.md` — packaging-time verification record.
- `VERIFIER_LEDGER.txt` — inherited and new verifier list.
- `inherited_rl27/` — complete RL27->RL28 handover, including the inherited RL21--RL27 verifier stack and earlier checkpoint material.
- `rl29_additions/` — two new exact/sanity verifiers.
- `rl29_experiments/` — reproducible finite evidence through depth 35 only.

The bundle intentionally does not promote unreproduced deeper exploratory observations.
