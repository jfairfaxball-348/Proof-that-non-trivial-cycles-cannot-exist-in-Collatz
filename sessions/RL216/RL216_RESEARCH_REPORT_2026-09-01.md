## Target attacked

RL216 inherited 331,935,285 bounded e=16 arithmetic candidates across 45,046 H21 prefixes and was tasked with finding a genuinely independent discrete or second-phase consumer, or otherwise proving the strongest no-go scope.

## Main advance

A new consumer is obtained by continuing the **actual lower/root odd trajectory forward from phase 16** rather than sharpening the RL215 real interval.

For every lifted candidate the exact state is

`y_16=2^34 eta-1-3^16*2^13`, `eta=eta_*+3^17 k`,

and the inherited root prefix has `h_16=1`. The true accelerated recurrence fixes

`a_i=v2(3y_i+1)`

`h_(i+1)=b_(i+1)-b_i+h_i-a_i >=0`.

This gives a discrete 2-adic forward height cone. It is independent of the RL214/RL215 interval inequalities and does not import RL209's signed-successor corridor.

## Exact deletion

The unique minimum-Q e=16 prefix has

`Q=43,013,953`, `eta_*=119,416,283 mod3^17`,

and RL215 leaves exactly `k=28,812..36,180`, i.e. 7,369 candidates. Its terminal Hensel filter removes none.

A modular residue-class sieve writes `k=r+2^m t`, propagates each current odd state affinely in t, splits only when a new 2-adic digit is required, and counts interval populations algebraically. It finds 6,219 disjoint failure residue branches covering all 7,369 candidates. Every branch makes a height negative by phase 174.

Thus RL216 deletes one exact prefix and all 7,369 of its lifts. The conservative promoted e=16 family is 331,927,916 candidates across 45,045 prefixes.

## Red-team boundary

An independent direct replay of all 7,369 candidates was used only as a red-team cross-check; it reproduced the modular failure-phase population exactly. The promoted projection is the residue/range-counting certificate, not the direct scan.

Deleting this prefix removes neither H21 state nor any of the four global mod18 classes. Its eta residue 1709 modulo2187 has eleven other exact prefix representatives, so all 469 RL212 reachable residues remain.

## Strategic consequence

The new route has bitten discretely for the first time at e=16: future work should generalize the same forward height cone across the remaining 45,045 prefixes using shared modular states, rather than enumerating 331,927,916 lifts. If that modular compression can delete every prefix, the e=16 terminal rank itself would become deletable; RL216 does not claim that step.

The quotient-residue and complementary-numerator-residue routes remain open but were not needed for the certified RL216 success.
