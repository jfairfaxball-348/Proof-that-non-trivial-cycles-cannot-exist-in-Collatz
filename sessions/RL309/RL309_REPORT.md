# RL309 — global mechanics review and redesigned roadmap

Date: 2026-09-13
Session type: PLANNING / GLOBAL LOGIC REVIEW ONLY

## 1. Top-level objective

The project objective is simply:

> Prove that a positive non-trivial Collatz cycle cannot exist.

No Gate, Bellman state, Radius theorem, selector, fixed prime, or local grammar is the project objective.

## 2. Central audit conclusion

Across the programme, many technically different routes repeatedly reach the same missing resource:

> an independent, global, physical, ownership-sensitive and gauge-invariant mechanism that works uniformly at arbitrary scale and forces a hypothetical cycle either into a bounded impossible witness or into a global cost that exceeds an independently proved budget.

This appears historically as missing coverage, ownership, ancestry, incidence, cancellation control, scale-growing discrepancy, branch domination, bounded-radius encounter, global lift, or physical reachability. These are not literally the same theorem, but they are manifestations of the same project-level scope deficit.

The principal strategic failure mode has therefore been:

`strong local obstruction -> attempt to build a global bridge afterward`.

The redesigned programme reverses that ordering:

`global all-scale extractor/coercivity -> bounded/owned witness -> local obstruction only if needed`.

## 3. Universal entrance object

RL310 must not begin from the retained one-excursion branch or from Gate A.

Begin one level earlier with the established genuine primitive-cycle encoding:

- a primitive positive hypothetical cycle;
- its parity word of length `A` with `L` odd positions;
- the full denominator `D = 2^A - 3^L`;
- genuine full-`D` divisibility/ownership of the parity-word numerator and its cyclic rotations;
- the integer quotient layer `R_m = Q_m / D`, where applicable in the established encoding;
- the exact cyclic/full-word transport identities already proved in the project.

The quotient layer is especially valuable because it is genuinely ownership-sensitive and follows the ordinary affine `+1` update. The historical `D∤Q` local fake cannot enter this layer.

However, RL206 already rules out broad natural families of additive/coboundary and fixed-arc bounded rational compatibility arguments. RL310 must not simply repeat quotient-residual searches inside those dead families.

## 4. Redesigned backwards architecture

The primary chain is:

`hypothetical positive primitive cycle`

`-> universal full-D owned cycle object`  [PROVED / inherited project baseline]

`-> scale-growing global ownership/coercivity/extraction theorem`  [OPEN BUT WELL-FORMED; PRIMARY]

`-> either direct contradiction OR universally bounded owned witness`  [OPEN, output of primary theorem]

`-> existing obstruction library if needed`  [many local components PROVED]

`-> contradiction`

`-> no positive non-trivial cycle`.

The missing theorem must work uniformly in unbounded cycle parameters. Fixed-radius or fixed-depth information cannot be promoted to this role without a proved exhaustive all-scale lift.

## 5. Candidate end-to-end architectures

### Architecture A — universal full-D ownership coercivity/extraction — PRIMARY

Input: every hypothetical primitive positive cycle.

Use: full-D ownership, integer quotient states, cyclic transport/discrepancy identities, physical ownership, and other already-proved universal identities.

Missing theorem: a scale-changing result proving one of:

1. **owned compression** — every sufficiently complex survivor creates a primitive/full-D owned witness in a bounded obstruction class;
2. **owned replication** — a forced owned feature occurs at a growing number of independent owned locations until a global budget is violated;
3. **owned discrepancy/coercivity** — an owned discrepancy grows faster than the available zero/height/phase resource;
4. an equivalent direct full-phase contradiction.

If successful, this can bypass the old A/B split or reduce the final step to an already-proved local theorem.

### Architecture B — direct quotient / ordinary `+1` global contradiction — FALLBACK 1

Input: the same universal full-D cycle object.

Proved interface: integer quotient states obey the ordinary affine Collatz update.

Open target: a genuinely non-coboundary, non-fixed-arc, ownership-sensitive global theorem on that physical integer orbit yielding contradiction directly.

Known barrier: RL206 classifies several broad natural additive/rational residual families as insufficient. Any revival must explicitly leave those classes.

### Architecture C — whole-cycle growth / Diophantine contradiction — FALLBACK 2

Input: universal cycle population/product/full-word relations.

Open target: obtain an RL-specific restriction on the reduced `(A,L)` ratio, gcd, convergent structure, or another global arithmetic parameter strong enough to contradict the cycle.

Historical caution: ordinary approximation to `log_2(3)` and finite Farey/cascade branch work have repeatedly failed to provide global coverage by themselves.

### Architecture D — retained Gate A + Gate B — FALLBACK 3

This architecture remains mathematically valid and preserves extensive theorem-grade work.

But Gate A and Gate B are independent major global obligations in the retained architecture; they are not clean complementary cases and are not a sequential chain in which proving Gate A automatically feeds Gate B.

The current Bellman/scalar frontier is therefore frozen as a downstream technical resource rather than the default project roadmap.

## 6. Gate A / Gate B re-audit

Gate A:

- is the uniform terminal-area/valuation obligation in the retained one-excursion/full-phase architecture;
- remains open;
- proving it would close that obligation but would not by itself prove global exclusion while Gate B remains independent.

Gate B:

- is the global bridge from genuine ownership/full-denominator/full-phase structure to a contradiction/local obstruction;
- remains open;
- proving a merely branch-specific Gate-B witness does not close it; exhaustiveness is essential.

Therefore the A/B split is retained only as a fallback decomposition. A sufficiently strong universal full-phase or full-D contradiction may bypass both.

## 9. New project methodology

Future work proceeds backwards from the final theorem.

For every subgoal, the closeout must classify the **parent difficulty delta**:

- **EASIER** — removes an unbounded parameter, turns branch scope into universal scope, turns infinite search into finite exhaustion, reduces the number/strength of independent global arrows, or creates an independent global constraint;
- **LATERAL** — changes coordinates, deepens a finite grammar, improves constants, or proves a downstream local fact without shortening the parent global dependency;
- **HARDER** — replaces the target with an equally strong or stronger uncontrolled parameter/coverage problem.

No route receives automatic continuation from accumulated sophistication.

A strong technical theorem with lateral global-distance delta is retained as a tool but does not automatically define the next session.

## 10. Stop/pivot criteria

Freeze or pivot a route when it repeatedly:

- produces finite depth without a uniform lift;
- reveals a fresh unbounded context/ancestry parameter whenever the previous one is controlled;
- collapses to a coboundary, recurrence identity, or already-owned information;
- depends on a special branch without an exhaustive entrance theorem;
- re-embeds unrestricted Collatz dynamics;
- improves a local bound while the same global arrows remain unchanged.

Do not allow two consecutive downstream sessions to continue automatically if neither makes the parent global arrow strictly easier.

It must attack the all-scale missing theorem itself and must not default back to the frozen Bellman or P/Q frontiers.
