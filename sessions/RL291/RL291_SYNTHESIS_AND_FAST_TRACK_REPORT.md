## 13. Plain-English summary

The project has repeatedly built very powerful microscopes. Each microscope can rule out huge classes of fake cycle patterns, and some local Radius theorems are genuinely proved. But a hypothetical surviving pattern can often “look dangerous” locally while having many different histories, free boundary loops, or gauge-equivalent descriptions.

The late work finally separated those two things.

Instead of asking “what charge did this particular history accumulate?”, RL290 asks “from this actual physical state, how dangerous can the future ever be after paying for every real height increase?” That is the Bellman threat.

The audit says the best next step is to combine that future-danger score with the strongest thing the older work learned about the past: the fixed seed, the ballot ancestry, and the exact zero-rank/coupon cost needed to get there.

So the next question is very focused:

> Can a state be dangerous by `k` binary levels unless the genuine path from the fixed seed has already paid at least `k` units of canonical height?

If the answer is yes, Gate A closes. The audit finds this is now the shortest coherent route worth attacking first.
