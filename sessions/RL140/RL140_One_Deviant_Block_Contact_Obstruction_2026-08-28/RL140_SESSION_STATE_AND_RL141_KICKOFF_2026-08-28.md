# RL140 session state and RL141 kickoff

RL140 proves an exact full-ownership obstruction for height-one zero-contact
patterns with a single deviant reduced block.  The proof is a factor and size
argument, not a claim that all contact patterns admit a block decomposition of
this form.

RL141 should attack two-or-more deviant reduced blocks or another genuinely
physical state/run constraint on the block contact polynomial.  It must not
reuse raw contact counts, periodicity alone, or a second formulation of the
same full-return divisibility as though it were independent ownership.
