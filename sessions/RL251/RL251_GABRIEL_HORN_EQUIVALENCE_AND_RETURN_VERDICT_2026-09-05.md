## 4. Strongest rigorous conclusion

### Lemma RL251.1 — single-cell capacity cannot manufacture emptiness

Let level `n` consist of a finite set of surviving cells `S_n`. Assign every surviving cell a strictly positive weight `w_n(C)>0`. Define

`U_n = sum_{C in S_n} w_n(C)`

and

`L_n = min_{C in S_n} w_n(C)`

when `S_n` is nonempty.

Then

`S_n nonempty  =>  U_n >= L_n`.

Consequently a criterion `U_n < L_n` is equivalent to level `n` already being empty; it does not convert shrinking capacity into a new emptiness theorem.

For uniform depth-`n` cylinders of weight `c_n`, this specializes to

`U_n = N_n c_n`, `L_n=c_n`,

so `U_n<L_n` iff `N_n=0`.

Classification: **elementary analytic lemma**.

### Corollary RL251.2 — vanishing cylinder width/measure is insufficient

A nested compatible branch can occupy one cell at every depth while `w_n(C_n)->0`. Thus decreasing density, measure, cylinder width, or normalized height does not exclude an infinite compatible path without an additional obstruction such as eventual level emptiness, well-founded descent, or simultaneous multi-object occupancy whose aggregate cost is bounded below in the same resource.

Classification: **analytic/topological consequence**.
